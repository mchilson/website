**PromptRobot**, the easy-to-use graphical tool for Linux to store and run your obscure or complex command-line apps and bash commands with the click of a button, today announced the release of version 0.5.0, bringing usability improvement for Linux system administrators and everyday users alike. Changes in this version include the ability to clone an entry, prompt when deleting, slighly smaller row hight to conserve window real estate, font additions for terminal support, and updated libraries and framework.


**What is PromptRobot**  
PromptRobot is a lightweight and fast graphical tool for Linux to store and run your obscure or complex command-line apps and bash commands with the click of a button, without having to look them up every time or search through bash history.

Features:  
- Lightweight graphical interface to run saved terminal commands.  
- Save complex and infrequently used commands.  
- Supports both Bash and PowerShell for Linux.  
- Great for both Linux beginners and System Administrators.

PromptRobot is built to be simple, fast, dependable, and do one thing well following the NIX philosophy.

**Availability**  
PromptRobot 0.5.0 is available now for download as .deb and .rpm packages. For more information, visit [promptrobot.app](https://promptrobot.app).
